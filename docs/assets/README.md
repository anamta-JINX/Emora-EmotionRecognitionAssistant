# EMORA README assets

This directory is intentionally organised so every relative path in the root
`README.md` remains stable on GitHub.

```text
assets/
├── branding/
│   ├── emora-icon.png
│   ├── emora-wordmark.png
│   └── emora-readme-banner.png
├── demo/
│   ├── emora-tested-demo.gif
│   ├── emora-demo-poster.png
│   └── emora-success-gallery.png
├── evaluation/
│   ├── confusion_counts.png
│   ├── confusion_normalized.png
│   └── f1_per_class.png
├── screenshots/
│   ├── pages/
│   └── results/
└── PHOTO-NOTES.md
```

Do not rename these files without updating their paths in the root README.
