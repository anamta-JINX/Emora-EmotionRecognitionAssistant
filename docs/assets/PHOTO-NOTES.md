# Real-face documentation media

The README result screenshots contain photographs of real human faces because
the documentation was requested to demonstrate genuine facial-expression
inputs rather than generated or illustrated faces.

## Validation status

Each retained screenshot was produced after the displayed input was processed
through EMORA's image-upload workflow using the project's trained
`emora_model.h5`. Only examples whose returned class matched the intended
visible expression were included:

- Happy
- Sad
- Angry
- Surprise
- Fear
- Disgust

These screenshots demonstrate the product workflow. They are not an accuracy,
bias, safety, or clinical benchmark.

## Source note

The Sad, Angry, Surprise, Fear, and Disgust test photographs came from the
project owner's existing `Facial Expressions/` test directory. The Happy test
photograph was supplied in the project documentation workspace. The raw input
photographs are intentionally not duplicated in this README pack; only the
result screenshots are included.
