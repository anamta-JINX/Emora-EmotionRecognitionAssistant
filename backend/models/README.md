# Model files

Place the trained model files here:

- `emora_model.h5` — required by the web app and prediction scripts.
- `feedback_model.keras` — optional feedback model used by the web app.
- `feedback_model.h5` — optional desktop-GUI feedback model.

Temporary files such as `feedback_model.tmp.h5` or `feedback_model.tmp.keras`
are generated automatically and should not be copied manually.
